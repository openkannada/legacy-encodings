# Security

legacy-encodings holds tables, a reference reader and a conformance runner that read local text and run the converter you point them at. If you find a security problem, such as input that makes the reference reader or the runner hang or crash, or a tool that runs something it should not, email prasad@luminik.io instead of opening a public issue. Include the commit and the steps to reproduce it.

Wrong table entries, conversion mistakes and other bugs go in [GitHub issues](https://github.com/openkannada/legacy-encodings/issues).
